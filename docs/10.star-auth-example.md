# Star Auth 功能演示

这是一个需要Star验证的页面示例。

## 功能说明

当用户访问设置了 `starAuth: true` 的页面时，系统会：

1. 检查用户是否已经通过Star验证
2. 如果未验证，显示Star验证遮罩
3. 用户需要Star指定的GitHub/Gitee项目
4. 点击验证按钮进行检测
5. 验证通过后可以正常访问页面内容

## 配置方法

在markdown文件的frontmatter中添加：

```yaml
---
title: 你的页面标题
starAuth: true  # 启用star验证
---
```

## 技术实现

- **前端**: VuePress插件 + Vue组件
- **后端**: Go语言API服务
- **验证**: GitHub/Gitee API（当前为mock实现）
- **存储**: localStorage + 服务端token管理

## 注意事项

- 验证token有效期为24小时
- 支持多个仓库同时验证
- 开发环境下使用mock数据
- 生产环境需要配置实际的GitHub/Gitee API
