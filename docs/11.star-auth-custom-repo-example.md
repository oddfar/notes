# 自定义仓库Star验证示例

这是一个使用页面级自定义仓库配置的Star验证示例页面。

## 页面配置

本页面在frontmatter中配置了自定义的仓库列表：

```yaml
---
starAuth: true
starAuthRepositories:
  - name: "GitHub Campus"
    url: "https://github.com/oddfar/campus-example"
    platform: "github"
  - name: "Gitee Campus"
    url: "https://gitee.com/oddfar/campus-example"
    platform: "gitee"
---
```

## 功能特性

1. **页面级配置**: 每个页面可以独立配置需要验证的仓库
2. **单个仓库验证**: 只需要Star任意一个项目即可通过验证
3. **多平台支持**: 支持GitHub和Gitee平台
4. **灵活配置**: 可以为不同页面配置不同的仓库要求

## 使用场景

- 不同项目的文档需要验证不同的仓库
- 某些页面只需要验证特定的仓库
- 根据内容相关性配置对应的项目仓库
